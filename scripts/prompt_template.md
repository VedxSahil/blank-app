You are updating a single-page pre-market dashboard for the Indian stock market. The current index.html is attached below this prompt. Today's date and time in IST are given at the very end.

## Research

- Run at least 10 web searches for today's numbers and news before you write anything.
- Find: GIFT Nifty, Nifty 50 previous close, Sensex previous close, India VIX, USD/INR, Brent crude, S&P 500, Nasdaq and Dow (overnight), and FII and DII net flows for the previous session.
- Find 8 market headlines from today or the last trading day.

## Rules for every number

- For every number, give the source name and the time it was published. Show both in the tile.
- If a number cannot be found, write "not found". Never guess, estimate or invent a number.
- Do not copy a number from the old index.html unless you confirmed it again today.

## Expected open

- Work out the expected open as GIFT Nifty minus Nifty 50 previous close, in points.
- Label it "gap-up" if the result is clearly above zero, "gap-down" if clearly below zero, and "flat" if it is close to zero.
- If either number is "not found", show "not found" for the expected open. Do not estimate it.

## Headlines

- Exactly 8 headlines.
- Each one has: the headline, the source, a tone label (positive, negative or neutral), and one line on who it helps or hurts.

## Morning brief

- Five plain sentences.
- Use only numbers that appear on the page.
- Give no buy, sell or target-price advice. Name no stock as a pick.

## Page rules

- Keep the existing layout, dark theme, inline CSS and mobile-friendly design. No external scripts or links to external resources.
- Set the "Last updated" value to the current date and time in IST.
- Keep the title "Pre-Market Dashboard" and the section names "Expected open", "Top headlines" and "Morning brief".
- Keep this footer exactly: "For learning only. Not investment advice. Numbers come from web search and can be wrong. Check them before you rely on them."
- Do not add personal holdings, portfolio values or personal views on any stock.

## Output

Return only the complete updated index.html, from <!doctype html> to </html>. No explanation, no markdown code fences, no text before or after.
